# ECO Resort - Concept Website

A beautiful, mobile-first concept website for a luxury resort in Port Harcourt. I built this from scratch to show how a real resort website should look, feel, and convert visitors to bookings.

**Live Demo:** https://soludo23.github.io/Lumora-Eco-resort/
**Type:** Concept / Demo Project - Built for Portfolio
**Status:** V1 Live - WhatsApp Booking Active
**Author:** Soludo23 - Port Harcourt, Nigeria

![Resort Preview](images/hero.jpg)

## What I Built

I imagined a resort in Port Harcourt and built the full website with no template, no WordPress. Just pure HTML and CSS, structured like a real client project.

## Features

- Hero section with resort image and clear call to action
- Rooms and Suites showcase with prices
- Gallery section with resort images
- About the resort section
- WhatsApp Booking - Click to book directly on WhatsApp
- Fully responsive - Works perfectly on phone, tablet and laptop
- Fast loading - No heavy framework, pure HTML/CSS

## Why WhatsApp Booking?

Many Nigerian businesses use WhatsApp more than forms because it converts better. When a user clicks "Book on WhatsApp", it opens WhatsApp with a pre-filled message. This is a real feature used by real businesses in Nigeria.

## How To Run This Project

1. Clone this repo:
   git clone https://github.com/Soludo23/paradise-resort.git
2. Open the folder in VS Code
3. Double click `index.html` or open with Live Server

No need to install anything. It will run in your browser.
